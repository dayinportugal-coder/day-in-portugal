For help with Netmend Quiz, email dayinportugal@gmail.com. We read this address ourselves. Please include which product you are using (the Sheets or Forms add-on, or the website), what you expected, and what happened, without pasting private pupil, client or spreadsheet data if you can avoid it.

Guide and set-up: https://netmend.app/quiz/

Typical set-up (Forms add-on)

  1. Create or open a Google Form.
  2. Open Extensions → Netmend Quiz → Open Netmend Quiz.
  3. Create a free key at aistudio.google.com/apikey and paste it.
  4. Paste a lesson or type a topic, generate questions, review them, and add them to this form.

The add-on only edits the form you have open. It does not create a new form.

You can also use the website to build a quiz in the browser and, if you prefer, run the generated Apps Script yourself in your own account.

Pro licences are bought at Gumroad ($19 once, 14-day refund). Paste the licence key in Settings.

There is no telephone support and no public postal address on this site.
