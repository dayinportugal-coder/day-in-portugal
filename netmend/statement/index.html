FAQ

Does my bank statement leave my computer?

In the default heuristic mode, no. The page uses Mozilla's pdf.js library to read the PDF in your browser and build the spreadsheet locally. You can disconnect from the internet after the page loads and it still works. Optional AI mode, which is part of Pro, sends the extracted text from your browser to Google's Gemini API with your own key, never to a Netmend server.

What does the free plan include?

The free plan converts one statement a day in this browser, and only the first page. You can download CSV or Excel. Pro ($29, one payment) unlocks every page, batch files, and optional AI mode for messy layouts.

Which banks and formats work?

Any statement that is a real text PDF (you can select the text with the mouse). European formats such as 1.234,56 and 12/11/2026 are supported, as are UK/US 1,234.56 dates. Scanned image-only PDFs need OCR; AI mode can help with messy text layouts but cannot invent text that is not in the file. Bank-by-bank notes also live in the free bank guides.

Can I trust the totals?

Always check opening and closing balances against the statement. Layouts differ between banks, and a missed row will throw the running balance off. For official accounts, keep the original PDF.
