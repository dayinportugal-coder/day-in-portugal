The functions

=NETMEND_AI(prompt, [cells])

Ask anything, optionally about a cell or range: write, summarise, rewrite, answer. Free.

=NETMEND_TRANSLATE(text, language)

Translate a cell into any language, keeping tone. Free.

=NETMEND_EXTRACT(text, what)

Pull an email, a company, a price or a date out of messy text. Pro.

=NETMEND_CLASSIFY(text, "a,b,c")

Sort feedback, leads or tickets into your own categories. Pro.

=NETMEND_SENTIMENT(text)

Positive, Neutral or Negative for reviews and replies. Pro.

=NETMEND_LIST(prompt, [n])

A list that spills down the column: ideas, keywords, names. Pro.

Install in your Google Sheet (2 minutes)

  1. Open your Google Sheet and click Extensions → Apps Script.
  2. Delete what is in Code.gs and paste the Netmend code (button below). Click Save.
  3. Reload the sheet. A Netmend menu appears. Click Netmend → Set Gemini API key and approve Google's permission screen (the script only calls Gemini and, for Pro, Gumroad).
  4. Get a free key at aistudio.google.com, paste it, done. Type =NETMEND_AI("Write a haiku about", A1).

FAQ

Does Netmend see my sheet?

No. The script runs in your Google account and sends only the text in your formula to Google's Gemini API with your key. Netmend has no server.

Why use my own key?

Because then there is no monthly fee. Google's free Gemini tier is generous for normal sheet work. Limits are set by Google and can change.

What does Pro add?

No daily cap, the EXTRACT, CLASSIFY, SENTIMENT and LIST functions, and "Fill selected cells", which writes plain values so the sheet never recalculates the AI again.

Can my team use it?

Each person who installs the script uses their own key. The licence is per person.
