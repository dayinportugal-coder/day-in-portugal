Guide and set-up: https://netmend.app/sheets-ai/

Typical set-up

  1. Install the add-on from the Google Workspace Marketplace, or paste the open script from the guide into Extensions → Apps Script.
  2. Open Extensions → Netmend Sheets AI → Settings.
  3. Create a free key at aistudio.google.com/apikey and paste it. The add-on tests the key before saving it.
  4. Try =NETMEND_AI("Write a haiku about spreadsheets").

If Google shows an “unverified app” screen while the listing is still under review, that is Google's warning for apps that have not finished OAuth verification yet. You can stop and wait, or continue only if you trust the project.

Pro licences are bought at Gumroad ($19 once, 14-day refund). Paste the licence key in Settings.

There is no telephone support and no public postal address on this site.
